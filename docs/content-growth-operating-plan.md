# docnunez.com Content Growth Operating Plan

## Goals

- Make `docnunez.com` the canonical home for new health content.
- Modernize the strongest WordPress archive articles instead of blindly bulk-porting all legacy posts.
- Add SEO and medical-review gates before publication.
- Generate a promotion package for every article so each publication drives readership and subscriber growth.

## Publication pipeline

1. Pull current WordPress inventory.
2. Score posts by evergreen value, audience relevance, local/West Valley usefulness, SEO potential, and clinical risk.
3. Select a batch of 5-10 posts.
4. Generate review-ready static drafts and promotion packages.
5. Physician/editorial review for medical accuracy.
6. Run SEO audit and update internal links.
7. Publish to `docnunez.com`.
8. Promote via newsletter + social package.
9. Review analytics and subscriber growth weekly.

## Promotion package per article

- Newsletter subject lines, preview text, and body copy.
- Facebook/Threads copy.
- X/Twitter manual batch copy because the free API is read-only.
- LinkedIn copy.
- UTM-tagged links per channel.
- 48-hour follow-up reminder.

## Near-term cadence

- Publish 1-2 modernized evergreen articles per week.
- Publish West Valley/local updates twice monthly, with the option to increase during heat/air-quality events.
- Send a weekly or per-article MailerLite update depending on article volume.

## Automation status

Local pipeline scripts live in `content-pipeline/scripts/`. GitHub push/deploy automation requires GitHub credentials or a deploy key on the VPS.
